НОМЕРА v1.2.1 — веб-версия (HTML + JavaScript)
==============================================

Это браузерная игра. Godot, Unity и установка не нужны.

БЫСТРЫЙ ЗАПУСК НА КОМПЬЮТЕРЕ
1. Распакуйте архив в любую папку (именно распакуйте, а не открывайте внутри архива).
2. Откройте папку nomera-web.
3. Дважды щёлкните файл index.html — игра откроется в браузере.
   Подходят Chrome, Edge, Яндекс Браузер, Firefox, Safari.
4. Прогресс сохраняется в браузере автоматически.

ПРОВЕРКА НА ТЕЛЕФОНЕ (или если index.html не открывается)
1. Нужен Python 3: https://www.python.org/downloads/
   (при установке на Windows отметьте «Add Python to PATH»).
2. Запустите мини-сервер из этой папки:
     Windows — двойной щелчок по start-server.bat
     macOS   — двойной щелчок по start-server.command
               (если macOS не даёт открыть: правый клик → Открыть)
     Linux   — ./start-server.sh
3. На компьютере откроется http://localhost:8000
4. На телефоне (в той же Wi-Fi сети) откройте http://IP-компьютера:8000
   IP-адрес показывается в окне сервера. Если Windows спросит про брандмауэр — разрешите доступ.
5. Чтобы остановить сервер, закройте его окно.

УПРАВЛЕНИЕ
  Пробел — крутить номер        A — автокрутка (после покупки улучшения)
  ← / → — сколько номеров за раз 1–8 — вкладки
  Q / W / E / R — инструменты в мастерской
  Промокод для теста: START2026 (Настройки → Аккаунт)

ЧТО В ПАПКЕ
  index.html     — страница игры
  css/style.css  — оформление
  js/game.js     — игра (версия 1.2.1 с исправлениями)
  js/addons.js   — профиль, уведомления, VIP, промокоды

Сброс прогресса: Настройки → Аккаунт → кнопка сброса внизу.
